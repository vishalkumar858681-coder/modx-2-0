# ModX 2.0

## Run locally

1. Open this folder in VS Code.
2. In Terminal, run `npm run dev`.
3. Open [http://localhost:3000](http://localhost:3000).

## Project files

- Homepage copy and layout: `src/content/homepage.html`
- Styling and CSS motion: `src/app/globals.css`
- Homepage images: `public/modexa/img/`
- Full report, original export and walkthrough: `reference/Modexa-2.0/`
- Private MongoDB URI: `.env.local` (Git ignored)

## Checks

- `npm run lint`
- `npm run build`
